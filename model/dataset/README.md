# Dataset SKEMANYA

## 1. Base language corpus
A starter source candidate is the rights-cleared Indonesian Wikipedia extract dataset:
https://huggingface.co/datasets/apricitea/bahasa-indonesia-corpus

Dataset card states CC BY-SA 4.0 and provides source URLs and revision IDs per record. It contains only short article introductions and is small (roughly a few thousand records / a few hundred thousand estimated tokens), so it is **not enough** to train a capable general-purpose language model. It is only a small prototype corpus.

Before using it in a commercial model release, review the current dataset card, each record's provenance, attribution obligations, and ShareAlike implications for derivatives. Preserve attribution. The download script accepts only rows explicitly marked `rights_reviewed=true`, `license=cc-by-sa-4.0`, and `source=wikipedia_id`.

## 2. SKEMANYA instruction seed
`instruction_seed.jsonl` contains original synthetic examples written for this project. These are seed examples to demonstrate format and persona, not a sufficient instruction-tuning dataset.

## 3. Excluded sources
Do not include scraped news articles from media publishers unless SKEMANYA has written permission or a suitable license. Do not include personal, patient, confidential, or credential data.

## 4. Dataset stages
- Source data: provenance and license recorded.
- Normalized text: generated by `prepare_data.py`.
- Instruction tuning: generated from approved conversation examples.
- Evaluation: held-out examples, reviewed by humans.

## 5. Source-level rights review template
Use `source_rights_review_template.csv` to record each source/license group and, where possible, each record's identifier. A row is not approved merely because a license name is present. Confirm commercial reuse, model-training permission, attribution, ShareAlike, privacy, source terms, and reviewer decision. Unclear or missing entries stay excluded. The completed manifest must be referenced by `TRAINING_APPROVAL.json` before either pretraining or instruction tuning can run.
